## Benchmarks

The benchmark's repository includes the list of all benchmarks. The documentation for each benchmark contains further
information. Benchmarks are split into different folders, based on language:

- Java:
    - [array-hashing](https://github.com/argo-com/benchmarks/tree/main/language/java/array-hashing/README.md)
        - Simple **Micronaut** server with operation of finding the longest harmonious sequence (we define a harmonious
          array as an array where the difference between its maximum value and its minimum value is exactly 1) as
          workload.
    - [array-sorting](https://github.com/argo-com/benchmarks/tree/main/language/java/array-sorting/README.md)
        - Simple **Micronaut** server with operation of merging two arrays into one sorted array as a workload.
    - [hello-world](https://github.com/argo-com/benchmarks/tree/main/language/java/hello-world/README.md)
        - Simple **Java** server with only one *hello world* function.
    - [hello-world-micronaut](https://github.com/argo-com/benchmarks/tree/main/language/java/hello-world-micronaut/README.md)
        - Simple **Micronaut** server with only one *hello world* function.
    - [reflection-call](https://github.com/argo-com/benchmarks/tree/main/language/java/reflection-call/README.md)
        - Simple **Java** server containing reflective call.
    - [tree-traversal](https://github.com/argo-com/benchmarks/tree/main/language/java/tree-traversal/README.md)
        - Simple **Micronaut** server with operation of finding max tree depth as workload.
- Python:
    - [hello-world](https://github.com/argo-com/benchmarks/tree/main/language/python/hello-world/README.md)
        - Simple **Python** server with only one *hello world* function.
